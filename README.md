## About

HanziApp is a web application for learning Mandarin Chinese and preparing for the HSK 3.0 exam. It is designed for both Spanish and English speakers, with language selection available from the start, and combines active-recall flashcards, spaced repetition, and stroke-by-stroke writing practice in a single tool.

This project is developed for the **Software Engineering II** course (2026-II) at the **Universidad Nacional de Colombia**.

## Main features

- **HSK 3.0 vocabulary, levels 1 to 6**, organized by level and category, with meanings and example sentences in Spanish or English.
- **Audio pronunciation** for every word, so learners can listen to how it sounds.
- **Bilingual interface**: Spanish and English, selectable from the first use.
- **Spaced repetition** (FSRS) to schedule reviews based on how well each word is remembered.
- **Character writing practice** with stroke recognition.
- **Multiple study modes**: reading and translating, writing, listening, view-only, and reviewing mistakes.
- **Dictionary** with search by hanzi, pinyin, or Spanish/English.
- **Progress tracking**: daily streak, words learned, and progress per HSK level.
